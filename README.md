# Confirmation time in a permissioned retail CBDC: code, testbed and data

Companion repository for the paper *"Confirmation time in a permissioned retail CBDC: a queueing model validated on a Hyperledger Fabric testbed"* (H. Chaudhary, G. K.C., S. Shrestha, Kathmandu University).

Everything is in [`cbdc-v2-release/cbdc-v2-release/`](cbdc-v2-release/cbdc-v2-release/). Its [README](cbdc-v2-release/cbdc-v2-release/README.md) explains the layout. To rebuild the main tables and all figures from the saved results, open [`reproduce_paper.ipynb`](cbdc-v2-release/cbdc-v2-release/reproduce_paper.ipynb).

Archived on Zenodo: [10.5281/zenodo.23838921](https://doi.org/10.5281/zenodo.23838921) (release v2.0).

Project page: https://hritikchaudhary04.github.io/research/cbdc-confirmation-time/
